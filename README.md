# Конвертер единиц

## Назначение

Консольная программа на Python для перевода единиц измерения.

## Что умеет программа

1. Градусы Цельсия -> Градусы Фаренгейта
2. Километры -> Мили
3. Килограммы -> Фунты
4. Метры -> Футы
5. Литры -> Галлоны
6. Мегабайты -> Гигабайты
7. Часы -> Минуты
8. Сантиметры -> Дюймы

Если выбрать несуществующий номер или ввести не число, программа выведет ошибку.

## Новый функционал (практическая работа 2)

- Можно выполнять несколько преобразований подряд. После каждого преобразования программа спрашивает «Выполнить ещё одно преобразование? (да/нет)».
- Если ввести что-то кроме «да» или «нет», программа попросит ответить ещё раз.
- Добавлены новые преобразования: Мегабайты -> Гигабайты, Часы -> Минуты, Сантиметры -> Дюймы.

## Запуск

```
python main.py
```

## Как пользоваться

1. Запустите программу.
2. Введите номер конвертера.
3. Введите значение.
4. Программа выведет результат.
5. Введите «да», чтобы продолжить, или «нет», чтобы выйти.

## Пример работы

```
Выберите конвертер:
1. Градус Цельсия -> Градус Фаренгейта
2. Километры -> Мили
3. Килограммы -> Фунты
4. Метры -> Футы
5. Литры -> Галлоны
6. Мегабайты -> Гигабайты
7. Часы -> Минуты
8. Сантиметры -> Дюймы
Ваш выбор: 2
Введите километры: 10
10.0 км = 6.21 миль
Выполнить ещё одно преобразование? (да/нет): да

Выберите конвертер:
...
Ваш выбор: 6
Введите мегабайты: 2048
2048.0 МБ = 2.0 ГБ
Выполнить ещё одно преобразование? (да/нет): нет
Работа программы завершена.
```
