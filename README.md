# Конвертер единиц

## Назначение

Консольная программа на Python для перевода единиц измерения.

## Что умеет программа

1. Градусы Цельсия -> Градусы Фаренгейта
2. Километры -> Мили
3. Килограммы -> Фунты
4. Метры -> Футы
5. Литры -> Галлоны

Если выбрать несуществующий номер или ввести не число, программа выведет ошибку.

## Запуск

```
python converter.py
```

## Как пользоваться

1. Запустите программу.
2. Введите номер конвертера.
3. Введите значение.
4. Программа выведет результат.

## Пример работы

```
Выберите конвертер:
1. Градус Цельсия -> Градус Фаренгейта
2. Километры -> Мили
3. Килограммы -> Фунты
4. Метры -> Футы
5. Литры -> Галлоны
Ваш выбор: 1
Введите температуру: 36
36.0 C = 96.8 F
```
